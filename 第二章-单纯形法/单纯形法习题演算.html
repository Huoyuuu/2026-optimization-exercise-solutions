输入格式

第一行写目标：min 或 max 加线性表达式，如 max 3x1 + 2x2 - x3。

之后每行一条约束，支持 <=、>=、=（也认 ≤ ≥），系数可写分数或小数，如 1/2x1 + 0.5x2 <= 4。

默认所有变量非负，x1, x2 >= 0 这一行可写可不写。可选 # 标题: … 设置片头标题。
